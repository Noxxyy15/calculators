## Features

Basic arithmetic operations:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Usage

### Ada
```bash
gnatmake calc.adb
./calc
```

### APL
```bash
dyalogscript calc.apl
```

### Assembly (x86)
```bash
nasm -f elf64 calc.asm -o calc.o && ld calc.o -o calc
./calc
```

### Bash / Shell
```bash
bash calc.sh
```

### BASIC / QBasic
```bash
qbasic calc.bas
```

### C
```bash
gcc calc.c -o calc
./calc
```

### C#
